# ADR 001 — Export natif Proton chiffré

Statut : retenu pour le prototype synthétique, 19 septembre 2026.

Nous produisons un export natif chiffré Proton v1 avec des primitives standard
(cryptography / OpenSSL), indépendamment du code Rust de référence. Le cœur ne
lit ni n'écrit de fichier et n'effectue pas de requête réseau. L'importeur officiel
est une dépendance GPLv3 du seul programme de test Rust, épinglée par commit.
Le projet est distribué sous GPL-3.0-only ; le code tiers conserve sa licence.

| Choix | Atouts | Limites |
|---|---|---|
| Export Proton chiffré | Fichier transférable ; import officiel ; chiffrement authentifié ; aucune zone RAM nécessaire | Compatibilité à tester par build ; phrase de passe séparée ; plaintext transitoire en mémoire |
| Texte clair sur RAM disk | Interopérabilité avec importeurs texte | Secrets accessibles aux lecteurs du volume ; swap possible ; cycle de montage spécifique à l'OS ; nettoyage non garanti |

Le second choix n'est pas le parcours par défaut. Aucun gestionnaire de volumes
ou proxy n'est inclus. Aucun gain de sécurité absolue n'est attribué au langage,
à la RAM ou à l'effacement d'une variable Python.

La compilation de l'importeur ne prouve pas la compatibilité avec chaque version
distribuée. Le gate suivant est l'import manuel synthétique dans un build identifié.

Le gate manuel a ensuite été exécuté avec succès sur Proton 1.4.3 (6) : voir
`validation.md`. Cela ne généralise pas le résultat aux autres builds.
