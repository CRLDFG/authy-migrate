# ADR 001 — Native encrypted Proton export

Status: accepted for the synthetic prototype, September 19, 2026.

Produce Proton v1 native encrypted exports using standard cryptographic primitives
(cryptography/OpenSSL), independently of the Rust reference implementation. The
core performs no file or network I/O. The official importer is a GPLv3 dependency
of a separate Rust test harness, pinned by commit. This project uses GPL-3.0-only;
third-party code retains its applicable licenses.

| Option | Benefits | Limitations |
|---|---|---|
| Encrypted Proton export | Transferable file; official import; authenticated encryption; no RAM volume required | Compatibility must be tested by build; separate archive passphrase; transient plaintext in memory |
| Plaintext on a RAM disk | Compatible with plaintext importers | Volume readers can access seeds; swap may apply; OS-specific mount lifecycle; cleanup not guaranteed |

The second option is not the default workflow. No volume manager or proxy is
included. Language choice, RAM storage, and clearing Python variables do not
provide absolute security guarantees.

Compiling the importer does not prove compatibility with every distributed build.
The subsequent application gate passed on Proton 1.4.3 (6), as recorded in
`validation.md`. That result does not generalize to other builds.
